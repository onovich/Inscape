# Inscape

[English](README.md)

面向视觉小说和分支叙事的脚本语言、编辑器与轻量工具链。

![Inscape 封面](docs/cover.png)

## 项目包含什么

- 分支叙事脚本。
- 编辑器与本地工具链。
- 包含测试的多包工程。

## 快速开始

使用已安装的 .NET SDK 还原并构建：

```bash
dotnet restore
dotnet build
```

## 仓库结构

- `src/` — 应用与库的源代码。
- `tools/` — 开发与内容工具。
- `docs/` — 项目文档与设计说明。
- `tests/` — 自动化测试与校验材料。
- `samples/` — 可运行示例。

Inscape 仍在积极开发中，尚未达到商业可用级别。仓库已有较完整的实现和测试，但语言与编辑器契约仍可能变化。
