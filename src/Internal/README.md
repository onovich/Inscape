# Internal

Holds product code that belongs to the Inscape toolchain itself.

Allowed layers: `Compiler`, `Tooling`, `Cli`, `VSCode`, `LanguageServer`, and `Runtime`.

Do not place host-specific adapters, Unity code, generated artifacts, or packaging-only scripts here.

Directory formula: `Layer / Business / Role / File`. Layer and Business directories must document their own boundaries before code is moved into them.
