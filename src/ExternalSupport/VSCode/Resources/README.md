# Resources

Owns VSCode-packaged non-source assets for the Inscape extension.

- `Language` contains VSCode language configuration.
- `Media` contains command icons and other extension images.
- `Schemas` contains bundled JSON schemas.
- `Snippets` contains VSCode snippet contributions.
- `Syntaxes` contains TextMate grammars.

Runtime logic belongs in the package source directories. Shared editor-neutral semantics belong in Internal `LanguageServer` or `Tooling`.
